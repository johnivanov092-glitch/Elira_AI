# Reprocenter: страницы работ

На портале сохранена пагинация по 50 работ с навигацией сверху и снизу.
Во вкладке «Все» свежие загрузки идут первыми; поиск, фильтры и переход
к нужной странице из уведомления сохранены. Реализация:
`operator_pagination.py`, установленная в `/srv/repro_app/backend/`.

7 сентября 2026 ИИ-анализ удалён с портала и из интеграций Elira по запросу
владельца. Таблицы анализа удалены; таблицы клиентов, работ, вложений,
комментариев, отметок прочтения и новости сохранены. В Elira оставлено
общее управление MCP в настройках; используется прежний `Elira.bat`.

Рабочая конфигурация сервера: `/srv/repro_app/docker-compose.yml`.
Сборка и запуск: `docker compose -f docker-compose.yml build backend`,
затем `docker compose -f docker-compose.yml up -d --no-deps backend`.
Новый backend собран из исходного образа портала с текущим кодом и пагинацией.

Перед удалением сохранена актуальная база и код в закрытом каталоге
`/srv/repro_app/backups/remove-ai-20260907`. База из прошлого дня не
восстанавливалась. Проверка до/после подтвердила сохранение 835 записей работ,
151 вложения, 658 комментариев и всех 987 файлов в каталоге загрузок.
