# Установка нового MCP-сервера

Применяй, когда задаче нужен сервер, которого нет в `mcp(action='list')`.
Подключённые серверы описаны в `data/mcp_servers.json` (папка data — родитель
папки навыков); у каждого есть навык `<id>-mcp`.

## 1. Найти сервер

- Источник — официальный репозиторий производителя, реестр
  `registry.modelcontextprotocol.io` или известный открытый репозиторий
  (`web_search`, `web_fetch`). Проверь: лицензию, дату последних изменений,
  транспорт (stdio — запускаемая программа; http — адрес сервера), что нужно для
  входа (токен, логин), умеет ли он только чтение.
- Сервер, который требует облачный ИИ-инференс, не ставь: у Elira всё локально.

## 2. Установить в свою папку

Папка сервера — `data/mcp/<id>/` (`<id>` — латиница, цифры, `_`/`-`). Своё
окружение там же, не в `backend/.venv`:

- Python: `python -m venv "<data>/mcp/<id>/.venv"`, затем
  `"<data>/mcp/<id>/.venv/Scripts/python.exe" -m pip install <пакет>`.
- Node: `npm install --prefix "<data>/mcp/<id>" <пакет>`; запуск —
  `node` с путём к скрипту пакета в `node_modules`.
- Готовая программа — положи в эту папку.
- Запиши источник, версию и лицензию в `data/mcp/<id>/SOURCES.md`.

HTTP-серверу папка не нужна, если он уже работает где-то в сети.

## 3. Записать в конфиг

`mcp(action='add', server_id='<id>', config={...})`:

- stdio: `{"description": "одна строка — что умеет", "command": "<полный путь к
  python.exe/node/программе>", "args": [...], "cwd": "mcp/<id>", "env": {...}}`
  (`cwd` относительно папки data или абсолютный).
- http: `{"description": "...", "transport": "http", "url": "http://host:port/mcp",
  "headers": {...}}`.
- Пароль, токен, ключ в открытом виде не принимаются: `add` покажет карточку для
  ввода секрета, в конфиг попадёт ссылка `sref_…` в `env_secret_refs` (stdio) или
  `secret_header_refs` (http).
- `add` у существующего сервера меняет только переданные поля.

## 4. Написать навык

`data/skills/<id>-mcp/SKILL.md` по образцу других `*-mcp`: что умеет, когда
применять, как запускать (`query` из имён нужных инструментов), 3–5 главных
инструментов с параметрами, порядок работы, ограничения, где лежит код.

## 5. Проверить

1. `mcp(action='start', server_id='<id>')` — в ответе список инструментов.
2. Один читающий вызов (статус, список, поиск) и сверка с ожидаемым.
3. Ошибка запуска — читай текст ошибки и `last_error` в `mcp(action='list')`,
   чини установку или конфиг; повтор без изменений не помогает.
4. Только после успешной проверки используй сервер в задаче. В итоге сообщи,
   что поставлено, куда, какая версия и что проверено.

## Сломалось после изменения

Конфиг правится `mcp(action='add')` или обычной правкой `data/mcp_servers.json`;
следующий `start` сам перезапустит процесс с новой записью. Улучшение
работающего сервера — копией в новой папке с проверкой, прежнюю конфигурацию
сохрани до успешной проверки.
