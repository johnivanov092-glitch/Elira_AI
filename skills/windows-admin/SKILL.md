1. Начни с заданного компьютера и симптома. Для службы прочитай service.md и
   выполни один inspect_service.ps1: service/process/events, время, команды,
   elevated_admin_token, integrity_sid/level. После ok=true переходи к заключению
   и выдаче файла; не создавай второй сборщик/P/Invoke. Исходник нужен при ошибке.
2. Если запрошен файл: capability_load с {"group":"resources"}, затем встроенный
   resource_publish с {"project_path":"service.json"} (настоящий относительный путь).
   Это не Python-модуль/CLI. Дай download_url; при конфликте имени повтори выдачу
   с уникальным download_name. Один путь на диске не выдача.
3. Для задания, ACL и диска прочитай нужную ветку scenarios.md. Установи ОС,
   PowerShell, учётку и права процесса проверки. Членство учётки в Administrators
   не доказывает повышенный токен; активную роль и integrity проверяет сценарий.
4. Локально — run_bash, удалённо — общий linux-admin/admin.py со ssh_run_ps из
   ../linux-admin/scenarios.md. Он сам кодирует скрипт. При заданном alias/IP не
   начинай с hosts; windows_inventory нужен для общего состояния.
5. До правки сохрани нужные настройки для отката: start mode/account/dependencies,
   XML задания, ACL и данные. Не отключай UAC/антивирус/firewall из-за неясной ошибки.
   Для файлов используй одну оболочку и LiteralPath; перед рекурсивным удалением/
   перемещением проверь абсолютный путь и принадлежность разрешённому каталогу.
6. Сохраняй UTF-8 без BOM и LF, русский текст. PS 5.1 Set-Content/Out-File Encoding
   utf8 добавляет BOM; ASCII теряет кириллицу. OutputPath готового сценария сохраняет
   правильно. Не считай неизвестный каталог мусором без владельца/зависимостей.
7. После изменения проверь реальную службу/PID, свежие события, прикладной health
   и пользовательский сценарий; сохрани до/после, команду, exit_code и время.
   Успех PowerShell не доказывает работу приложения. Доступ запрещён, объект не
   найден и нет событий — разные исходы; отмечай фильтр/лимит. Фоновые процессы —
   через существующий run_server; окно помощника скрывай. Секреты не выводи.
