# Встроенные навыки Elira (заводской набор)

Эти папки — заводской набор. При первом запуске Elira копирует недостающие навыки
отсюда в рабочую папку навыков `data/skills/`; дальше навыки живут там, и Elira
читает, применяет и правит их обычными инструментами. Существующие навыки в
`data/skills` релиз не перезаписывает. Подробно: [`docs/TASK_SKILLS.md`](../docs/TASK_SKILLS.md).

`.agents/skills` содержит навыки инструментов разработки репозитория и в Elira не
подключается.

Каждая папка содержит `SKILL.md`: YAML frontmatter с `name` (как имя папки) и
`description` (до 320 символов), затем Markdown-инструкция (до 8000 символов).
`metadata.title` задаёт русское имя.
