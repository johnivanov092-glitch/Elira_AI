# Навыки Elira

Этот каталог содержит инструкции самой Elira. `.agents/skills` содержит навыки
инструментов разработки репозитория и автоматически в Elira не подключается.
Каталог Elira всегда находится внутри установленного проекта, независимо от
подключённого рабочего репозитория и текущего пользователя Windows.

В обычном запросе достаточно описать задачу. Модель видит краткие описания всех
навыков и выбирает инструкции до профильной работы. Можно явно попросить:
«Используй навык python для этой задачи». Специального slash-синтаксиса нет.

`runtime_control(operation="skill_list")` возвращает полный каталог;
`runtime_control(operation="skill_load", name="python", query="причина выбора")`
загружает выбранную инструкцию. Это чтение, оно не меняет права выполнения.

Каждая папка содержит `SKILL.md`: UTF-8 без BOM, LF, YAML frontmatter с `name`
и `description`, затем Markdown. `metadata.title` задаёт русское имя в UI.
Описание ограничено 320 символами, инструкция — 8000 символами, файл — 24000
байт. Всего поддерживается 40 пакетов, активные инструкции ограничены 24000
символами. Переполнение возвращает ошибку, уже загруженные инструкции сохраняются.
`disable-model-invocation: true` запрещает загрузку пакета; отдельного режима
ручного обхода этого ограничения нет. Невалидные пакеты видны в диагностике
`skill_list`, их инструкции не загружаются.

Установка пакета — осознанное добавление проверенной папки в этот каталог.
Автоматического скачивания, установки из подключённого проекта или чтения
каталогов Codex/Claude нет. Наличие `allowed-tools` не выдаёт разрешений; поля
сторонних интеграций не создают соответствующие возможности Elira. Сначала
проверь совместимость инструкции с её существующими инструментами.

Дополнительные файлы можно держать рядом с `SKILL.md`: загрузчик возвращает
абсолютный каталог, а нужные справочники читаются обычным `read_file`. Скрипты
сами не запускаются; выполнение проходит через существующий executor и Workflow.

Перед использованием инструкции применяется общая редакция секретов; SHA-256
вычисляется уже по тексту, который реально получает модель. Загруженная версия
сохраняется как снимок с этим SHA-256 в журнале текущего прогона.
Повторная загрузка не дублирует её. Compaction сохраняет полный активный блок;
Resume восстанавливает снимок того же прогона. Изменение текста пакета на диске
вступает в силу в новом прогоне; удалённый, отключённый или повреждённый пакет
останавливает Resume с явной ошибкой. Новый пользовательский запрос получает
каталог заново и не наследует полные инструкции завершённой задачи.
