# Финансовые расчёты

Все параметры на верхнем уровне JSON. Деньги и проценты задавай десятичными строками.
Ставки, цены, сроки и валюту предоставляет пользователь; навык их не получает из сети.
`places`: целое 0–6 (по умолчанию 2) для денежных результатов. Процентные результаты
имеют фиксированную точность: percent_of — 4 знака, остальные — 2; ROUND_HALF_UP.
`prices_include_vat` — строго JSON boolean, дробное/boolean places отвергается.

| operation | Параметры |
| --- | --- |
| `invoice` | `items`: 1–500 объектов `{name,qty,price}`; qty по умолчанию 1, qty/price ≥0. `markup_percent` ≥0, `discount_percent` и `vat_percent` 0–100; пропущенные ставки =0. `prices_include_vat`: JSON boolean. Сначала округляется цена с наценкой, затем строка, скидка и НДС. |
| `vat_add` | `amount`, `vat_percent` ≥0: начисление сверху. Ставка обязательна. |
| `vat_extract` | `amount`, `vat_percent` ≥0: выделение из цены. Ставка обязательна. |
| `markup` | `cost`, `markup_percent`: цена и прибыль; наценка считается от себестоимости, маржа — от цены. |
| `margin` | `cost`, `price`, оба ненулевые: прибыль, маржа и наценка. |
| `price_from_margin` | `cost`, `margin_percent` <100: цена под заданную маржу. |
| `discount` | `amount`, `discount_percent` ≥0: скидка и остаток. |
| `percent_change` | `old` ≠0, `new`: изменение и процент относительно `abs(old)`. |
| `percent_of` | `part`, `whole` ≠0: доля в процентах. |
| `loan_payment` | `amount` ≥0, годовой `rate_percent` ≥0, целый `months` 1–1200: аннуитет; итог из округлённого месячного платежа. |
| `split` | `amount`, 1–500 неотрицательных `weights`, сумма весов >0: остаток округления отнесён на самую крупную долю (при равенстве — первую). |

Сохранены прежние допустимые диапазоны: отрицательные суммы возможны там, где нет
явного ограничения; отдельные VAT/discount операции не вводят верхний порог 100%.
Это арифметика, а не подтверждение допустимости ставки, кредита или налоговой операции.
Изменяй скрипт здесь обычными файловыми инструментами, проверяя результат на примерах.


| Дополнительная operation | Параметры и допущения |
| --- | --- |
| compound_interest | principal ≥0, rate_percent >-100 **за период**, periods 0–1000, contribution ≥0 по умолчанию 0 (в конце каждого периода). |
| depreciation | cost ≥0, salvage 0..cost (0), life 1–1000, period 0..life, method straight_line (по умолчанию) или declining_balance; для declining_balance нужен rate_percent 0–100. В конце life не производится скрытое списание остатка. |
| break_even | fixed_cost ≥0, unit_price > variable_cost ≥0. Возвращает точное и округлённое вверх количество, выручку. |

Дополнительные операции принимают currency как подпись и places 0–20 (по умолчанию 2).
Пример: `{"operation":"compound_interest","principal":"100000","rate_percent":"10","periods":2}`.
Для НДС Казахстана отдельно прочитай KZ_VAT.md; арифметика не подтверждает юридическую ставку.
