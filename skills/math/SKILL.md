Единый математический навык вместо calc, unit_convert, finance и finance_calc.
Для финансов используй готовую финансовую операцию, для инженерных задач — техническую;
не переписывай ту же формулу отдельным скриптом. Код и инструкции навыка изменяемы.

1. Выбери операцию. Арифметика: `{"operation":"evaluate","expression":"0.1+0.2"}`.
   Для остальных прочитай **только нужный справочник**:
   - FINANCE.md — счета, НДС, проценты/маржа, кредиты, амортизация, безубыточность.
   - ALGEBRA.md — выражения, уравнения/неравенства, анализ, матрицы, оптимизация.
   - DOMAINS.md — геометрия, тригонометрия, статистика, вероятность, единицы, биты, графы.
   - TECHNICAL.md — сети, RAID, объёмы, передача, электричество, камеры.
   - DATES.md — календарь, сроки, праздники, часовые пояса.
   - PLOTS.md — PNG функций, распределений и зависимости по точкам.
2. Запиши JSON UTF-8 в рабочую папку. `operation` и все её параметры — на верхнем уровне.
   Для точных чисел используй строки: `"0.1234567890123456789"`, `"1/3"`.
   Денежные операции также понимают `"125 000,50 тг"`; остальные числовые выражения —
   десятичную точку, дроби, pi, sqrt. Не угадывай исходные ставки, измерения или единицы.
3. Запусти единственный CLI:
   `"<папка навыка>/.venv/Scripts/python.exe" "<папка навыка>/calculate.py" --input "<запрос.json>"`
   Linux/macOS: `.venv/bin/python`. Если .venv отсутствует, создай её Python 3.10+ и
   установи `requirements.txt` **внутрь навыка**. Окружение приложения не изменяй.
   Обычные финансовые операции и date_info также работают на стандартном Python.
   `--output "<результат.json>"` сохраняет JSON; существующий файл защищён,
   замена только с `--overwrite`. Вход и выход различаются. Вход ≤2 МБ.
4. Проверь exit code и `ok`: успех — 0/true, ошибка — 1/false с причиной.
   В результате различай точную форму `exact`, десятичную `decimal`, `approximate`.
   `places` задаёт округление HALF_UP, обычно 0–20; у финансов свои шкалы в FINANCE.md.
   Пояснение — `formula`, `substitution`, `units`, `precision` в result или explanation.
   Символьное множество с ConditionSet не означает найденное явное решение.
   Неподдерживаемая задача/таймаут — повод уточнить модель расчёта, а не заявить результат.
5. Ответ: формула → подстановка → значение с единицами и округлением. Для документа
   передай вычисленные значения document-create. Для скачивания JSON/PNG/документа
   вызови resource_publish и используй выданную ссылку. Локальный путь не является выдачей.

Навык не читает сеть, не подбирает ставки и не публикует файлы сам. Символьные операции
ограничены 15 секундами; списки, матрицы, графы и выборки имеют пределы размера.
График — численная выборка, не доказательство непрерывности или глобального экстремума.
Дифференциальные уравнения оставлены на следующий этап.
