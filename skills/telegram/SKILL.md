Реализация и сценарии находятся в этой папке. Запуск через обычный run_bash;
действуют выбранные пользователем разрешения. Python — окружение Elira
(ELIRA_BACKEND_ROOT), которое предоставляет общие хранилища и настройки.

1. Создай UTF-8 JSON-файл с аргументами сценария в рабочей папке.
2. Запусти `python <папка-навыка>/telegram.py send --input <args.json> --output <result.json>`.
3. Проверь `ok`, `status` и фактические данные. Ошибку не выдавай за успех.
4. Для списка сценариев используй `--help`. Не выдумывай аргументы командной строки.

Точный формат аргументов и сценарии: прочитай scenarios.md перед первым запуском.

Исполняй через Python Elira или собственное окружение с зависимостями приложения.
Путь backend передаётся средой ELIRA_BACKEND_ROOT при запуске из Elira.
