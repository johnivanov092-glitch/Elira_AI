## История и доказательства

[Архив](archive/README.md) содержит прежние планы, дубли карт агента, backlog,
отчёты приёмки, исследования и эксперименты. Их результаты и ограничения
сохранены; они не являются текущей очередью задач или проверкой работающего релиза.

Пути `.scratch/`, `.runtime/` и `.agent/` в отчётах обозначают локальные артефакты,
обычно исключённые из Git. Прежние отслеживаемые PRD перенесены из `.scratch/` в
`archive/plans/` и не становятся новыми поручениями. Актуальная работа определяется запросом
пользователя и соответствующей локальной задачей.

## Серверный репозиторий

Инференс обслуживает соседний `Elira_AI_Server`. Его полные эксплуатационные
документы находятся вне этого репозитория: `../Elira_AI_Server/README.md`,
`../Elira_AI_Server/Server/ACCESS.md`, `../Elira_AI_Server/docs/README.md`.

## Поддержание порядка

- Текст: UTF-8 без BOM, окончания строк LF; русский текст сохраняется кириллицей.
- Корень содержит точки запуска, инструкции проекта и конфигурацию сборки/инструментов.
- Документация размещается в `docs/`, вспомогательные скрипты — в `scripts/`,
  визуальные исходники — в `assets/`.
- Устаревшие материалы переносятся в `archive/` с сохранением результатов и ссылок.
- Публичные документы не содержат секретов, локальных `.env`, runtime-баз и журналов.
- Снимок тестов, дата документа и Git commit не подтверждают установленную версию.
