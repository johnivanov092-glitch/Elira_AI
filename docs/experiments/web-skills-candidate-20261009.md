# Web skills + calendar: кандидат 09.10.2026

Пользователь разрешил слить все рабочие изменения в main и создать кандидат после обсуждения известных ограничений. Установка не запрошена. Предполагаемый ID: web-skills-calendar-20261009-r1.

## Состав

- Web-поиск через SearXNG, чтение страниц, извлечение, корпус, источники/цитаты, HTTP и Chromium/Playwright перенесены из app в изменяемый пакет skills/web-research (seed для data/skills).
- CLI search/fetch/query/browser/http/screenshot/verify/status запускается существующим run_bash. Новый executor/provider/registry не добавлен.
- Удалены builtin web_search/web_fetch/web_query/browser/http_api, группа web и специальная веб-оркестрация ядра. Исторические записи источников сохранены через legacy_sources; не выдаются за новые проверенные источники CLI.
- Web-PDF: документ читает document-read, веб-навык сверяет URL/байты/SHA-256 и сохраняет извлечение. В новом пути это проверка навыка, а не независимая аттестация ядром.
- Автоматическая браузерная проверка run_server заменена явным вызовом навыка; прежние специализированные HTTP API навыков возвращают 410.
- weather: офлайн JSON, вычисленные дни недели, единицы из daily_units, предупреждение об отсутствующих единицах; уточнены инструкции.
- Встроенный календарь: день недели в runtime-контексте и операция date_info существующего calc, включая валидацию ISO-дат и високосных годов.
- Обновлены инструкции code-change, document-read, mcp-install, playwright-mcp; 15 модулей компонентных Web-тестов перенесены вместе с кодом (369 тестов).
- Добавлены тесты календаря и сохранены отчёт сравнений/диагностические исходники.

## Что уже было в main

Все остальные существующие ветки являются предками main: история/Resume/сжатие, терминальный протокол модели, Qwen, narration, перенос документов/OCR/финансов/Computer Use, DOCX-превью и предыдущий Web-PDF контракт. Повторное слияние их старых вершин ничего не добавляет. Отклонённые prompt-english и skill-action-scope отсутствуют среди локальных веток и не включены.

## Обязательные ограничения кандидата

- Кандидат подготовлен для дальнейшей проверки; не считать verified или готовым к установке.
- Общий backend-набор не собирается: 40 тестовых файлов ещё завязаны на удалённые builtin Web API/guards. Их не удаляли и не ослабляли ради зелёного статуса.
- Изменяемые источники CLI не привязаны к прежнему источниковому UI/аттестации ядра. Browser cancellation после переноса на процесс shell требует дополнительной приёмки.
- Стабильный неизменённый golden 29/29 не доказан. Golden-файл не менялся. Полный pytest отложен до устранения ошибок сборки тестов.
- В 23 модельных прогонах проверены погодные варианты и календарь; последние 3 погодные таблицы правильные, но свободный текст один раз содержал неверную долготу. Автовыбор weather без готового JSON отдельно не подтверждён.
- Factory-навыки содержат исходники и requirements; пользовательские существующие data/skills не перезаписываются автоматически. Окружение web-research должно быть создано в data/skills перед рабочим использованием; текущая проверенная .venv находится только в песочнице.
