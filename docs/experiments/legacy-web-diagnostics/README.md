# Диагностики прежнего встроенного Web

Неизменённые снимки двух незакоммиченных диагностик из worktree agent-run-diagnosis.
Они проверяют прежний builtin-транспорт и не являются тестами нового навыка.
Сохранены как текст для воспроизводимости истории; исходники в старом worktree не изменены.
Проверки общего backend не отключались: их 40 ошибок импорта после переноса Web остаются блокером верификации кандидата.
