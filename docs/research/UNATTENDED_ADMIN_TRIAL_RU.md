# Самостоятельный прогон с последующим ревью

Решение пользователя: оставить агенту полные права администратора, UAC не менять.
Текущая Foundation рассчитана на неповышенный токен; этот прогон не переключает
рабочую установку на Foundation и не заявляет защиту от администратора.

Запуск: `Elira_Autonomy_Test.bat` из корня проекта, от имени администратора.
Он запускает локальный Python controller в фоне и сразу возвращает управление.
Никаких последующих обращений к Codex для наблюдения не требуется; работу выполняет
настроенная Qwen. Старый FAIL и прежний тестовый стенд сохраняются.

Скрипт создаёт новую `.scratch/autonomy-admin-<дата>-<id>`, берёт зависимости
у активного релиза и код из текущего Git HEAD. Незакоммиченные изменения приложения
не входят в прогон. Сначала собирается baseline, затем Qwen получает обычную цель:
скачивание ZIP папки диалогов. Реальный браузер проверяет кнопку и архив; при
наблюдаемой ошибке выполняется одна попытка ремонта. После этого проверяется
повторное использование на новых вымышленных чатах. Если ремонт не потребовался,
его покрытие остаётся `NOT_OBSERVED`. Native Tauri и Foundation имеют `NOT_RUN`.

Результаты: путь последнего прогона записан в `.scratch/autonomy-admin-latest.json`.
В каталоге прогона находятся `RESULT.json`, `controller.log`, журналы SSE,
снимки релизов, отчёты браузера, ZIP и сравнение состояния рабочей установки.
`REVIEW_REQUIRED` означает завершение автоматических шагов, а не окончательную
приёмку. `FAILED_REVIEW_REQUIRED` сохраняет причину ошибки для разбора.

Лимиты существующего стенда: до часа на один модельный этап; отдельный supervisor
до четырёх часов. Модели не скачиваются. Локальные сборки занимают диск и CPU;
используется существующий Cargo cache. Повторный запуск создаёт новый прогон.
Скрипт рассчитан на этот компьютер и переиспользует локальные acceptance helpers
из `.scratch/autonomy-ui-acceptance` и `.scratch/autonomy-compaction-acceptance`.

Подготовка проверена разбором Python и `--help`. Сам живой прогон при подготовке
не запускался. Полные административные права сохраняются: отдельная тестовая
папка задаёт область задачи, но не является изоляцией прав Windows.
