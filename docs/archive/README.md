# Архив документации

Исторические материалы сохранены для проверки решений и результатов. Они
описывают свои даты и версии кода; открытые вопросы в них не являются новым
поручением. Действующая навигация — [документация Elira](../README.md).

## Отчёты и эксперименты

- [retired-tests/](retired-tests/) — снимки удалённых проверок для истории.
- [plans/](plans/) — прежние отслеживаемые PRD и этапы IT Ops/Workflow из
  `.scratch/`; локальная очередь задач и рабочие журналы остаются на месте.

- [research/](research) — датированные исследования и приёмки автономности,
  Windows Foundation, моделей, восстановления и CPU-эксперимента Laya.
- [experiments/](experiments) — эксперименты с навыками и Web от 09.10.2026.
  Исходные диагностические снимки `.txt`, JSON-результаты и ограничения проверок
  сохранены; эти снимки не входят в действующий pytest-набор.
- [BACKLOG.md](BACKLOG.md) — прежняя сводка продолжения работ.
- [POST_SERVER_BACKLOG.md](POST_SERVER_BACKLOG.md) — миграция на локальный сервер
  и прежние измерения качества.
- [ARCHITECTURE_SIMPLIFICATION_AUDIT_RU.md](ARCHITECTURE_SIMPLIFICATION_AUDIT_RU.md) —
  снимок рефакторинга от 23.08.2026.
- [AGENT_STRUCTURE.md](AGENT_STRUCTURE.md) и
  [ELIRA_SELF_MODEL.md](ELIRA_SELF_MODEL.md) — прежние карты
  агента; текущие владельцы перечислены в [PROJECT_MAP.md](../PROJECT_MAP.md).
