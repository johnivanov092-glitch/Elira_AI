# Пользовательский голос Elira

Текущий TTS Elira — **Silero v4_ru** на CPU, HTTP-сервис `:8005`. Он даёт
фиксированный набор русских голосов и не поддерживает zero-shot cloning или
установку пользовательского голоса как отдельного ONNX-файла. Поэтому старый
процесс обучения и установки Piper к текущему runtime неприменим.

Выбор существующего голоса идёт через Settings → «Голос». Канонический контракт
клиента: `GET /health`, `GET /voices`, `POST /tts`; базовый URL задаётся
`ELIRA_TTS_URL`.

## Если понадобится клонирование

Это отдельная замена TTS-сервиса, а не настройка Silero. Минимальный безопасный
план:

1. Выбрать движок с подтверждённой поддержкой русского и voice cloning.
2. Зафиксировать тот же HTTP-контракт либо добавить совместимый adapter в
   существующий voice runtime — не создавать второй TTS path в агенте.
3. Ограничить размер текста, concurrency, timeout и GPU/CPU budget; возвращать
   явные fail-closed ошибки.
4. Использовать голос реального человека только с его явным согласием и хранить
   dataset/model вне git.
5. Прогнать API-контракт, latency и ручное сравнение качества до переключения
   `ELIRA_TTS_URL`.

Подготовка согласованного датасета остаётся доступна через
`scripts/voice_dataset_prep.py`; сервис Faster Whisper на `:8006` создаёт
черновые транскрипты, которые необходимо вычитать вручную. Сам скрипт не
обучает модель и не делает текущий Silero клонируемым.
