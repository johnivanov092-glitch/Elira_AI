# Voice samples — Silero TTS (Elira)

Референс-сэмплы, сгенерённые при подборе голоса Elira (2026-07-05, Silero `v4_ru`).
Аудио (`*.wav`) в git не коммитится (см. `.gitignore`) — это локальный референс.

## Итоговая конфигурация (что реально стоит)
- Движок: **Silero v4_ru** (правильные русские ударения), self-hosted на AI-сервере.
- Голос: **kseniya**, **24 кГц**, шумодав **выключен** (raw).
- Сервис: systemd `silero-tts` → `http://192.168.88.15:8005` (контракт Elira: `/health`, `/voices`, `POST /tts`).

## Что за файлы
| Файл | Что это |
|---|---|
| `aidar/baya/kseniya/xenia/eugene.wav` | первый батч, все голоса v4_ru **@ 48 кГц** |
| `*_24k.wav` (kseniya/xenia/baya) | те же голоса **@ 24 кГц** — чище, без «металлического двоения» |
| `xenia_48k.wav` | xenia @48к (контроль двоения) |
| `kseniya_clean.wav`, `GENTLE.wav` | эксперименты с шумодавом (noisereduce) |
| `RAW.wav` | вывод сервиса без шумодава |
| `FINAL_kseniya_service.wav` | вывод полного пайплайна (историческая версия) |

## Уроки (почему такая конфигурация)
- **48 кГц** давал «2 голоса внутри / металлическое двоение» = imaging-артефакт → лечится **24 кГц**.
- Агрессивный **noisereduce** (шумодав) давал «робот-эхо / 2-й голос» (musical noise) — хуже фона → **выключен**, raw чище.
- Silero ≈ Piper по классу (лёгкий/CPU, слегка синтетично). Для по-настоящему живого голоса — XTTS-v2 (тяжелее, отложено).
